✅ Сайт жүктелді!

Файл аты — index.html. Енді оны интернетке шығарыңыз. Ең оңайы — тегін GitHub Pages:

  1. github.com сайтында тіркеліңіз (тегін).
  2. New repository басыңыз. Атын мысалы mysite деп жазып, Public таңдаңыз, құрыңыз.
  3. uploading an existing file сілтемесін басып, index.html файлын салыңыз да, Commit changes басыңыз.
  4. Settings → Pages бөліміне кіріңіз. Branch ретінде main, папка ретінде / (root) таңдап, Save басыңыз.
  5. 1–2 минуттан кейін сайт сілтемесі шығады: аты.github.io/mysite. Осыны клиенттерге жіберіңіз.

Компьютерде тағы бір оңай жол: app.netlify.com/drop бетін ашып, ішінде index.html бар папканы сүйреп тастаңыз. Сілтеме бірден шығады.

Түймелердің аты уақыт өте өзгеруі мүмкін. Сайтты өзгерткіңіз келсе, KASIP.KZ-ке қайта кіріп, жаңа index.html жүктеп алыңыз да, қайта салыңыз.
